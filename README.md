# Set Padel

Um app web simples para encontrar quadras de padel em São Paulo e reservar um horário.

## Como usar

Abra `index.html` no navegador ou sirva a pasta com um servidor estático, por exemplo:

```sh
python3 -m http.server 8000
```

Depois acesse `http://localhost:8000`, escolha a região, a data e um horário disponível. As reservas ficam salvas no armazenamento local do navegador e podem ser canceladas na seção **Minhas reservas**.
